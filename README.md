# 미래 먹거리 노트

어떤 일로 먹고살 것인가에 대한 수익 아이디어를 카드로 모아 두고, 부담과 기대를 나눠 하나씩 따져 보는 정적 페이지다.

- 공개 주소: https://lodeym.github.io/future-income/
- `index.html`: 화면(타일 목록, 관계도, 상세 창, 입력 양식, 저장 설정)
- `ideas.json`: 아이디어 데이터. 화면 파일은 건드리지 않고 이 파일만 고치면 카드가 바뀐다.

## 페이지에서 직접 입력

'아이디어 추가'나 상세 창의 '수정'으로 입력한다. 저장 위치는 '저장 설정'에서 정한다.

- **이 기기(기본)**: 지금 쓰는 브라우저의 localStorage에만 저장된다. 다른 기기나 공개 페이지에는 보이지 않으며, 카드에 '이 기기' 표시가 붙는다.
- **GitHub**: Fine-grained 토큰(저장소 `future-income`만, Contents 읽기·쓰기)을 연결하면 저장할 때마다 GitHub API로 `ideas.json`을 바로 고친다. 커밋 작성자는 토큰 주인이다. 연결한 뒤 '이 기기 저장분'은 'GitHub에 올리기'로 한 번에 옮길 수 있다.

토큰은 그 브라우저의 localStorage에만 보관된다. 공용 PC에서는 연결하지 않는다.

## 관계도

위쪽의 `카드 | 관계도`로 바꾼다. 주소 끝에 `#graph`를 붙이면 관계도로 바로 열린다(https://lodeym.github.io/future-income/#graph).

- 점 하나가 아이디어 하나다. 점 크기는 종합 점수, 색 배경은 분류 묶음, 점선 테두리는 초안이다.
- 선은 서로 받쳐 주는 관계(`links`)다. 점을 누르면 연결이 진해지고, 옆 패널에 연결 이유가 나온다.
- 점은 끌어서 옮길 수 있다. 확대는 Ctrl+휠이나 두 손가락으로 한다(평소 스크롤은 페이지가 받는다).
- 분류·상태 필터와 검색이 관계도에도 그대로 적용된다.
- 그리기에는 d3 7.9.0(cdnjs)을 쓰며, 관계도를 처음 열 때만 SRI 해시를 확인해 불러온다.
- 이름표는 점의 아래·위·오른쪽·왼쪽 중 다른 이름표·점과 가장 덜 겹치는 자리에 놓는다.

## 화면 테마

기본은 밝은 화면이다(폰이 어두운 모드여도 밝게 연다). 도구 줄의 🌙 버튼으로 어두운 화면으로 바꿀 수 있고, 고른 값은 그 기기에만 저장된다(`localStorage`의 `future-income.theme`).

## 목표 상자

`ideas.json` 맨 위의 `goal`을 페이지 머리말 아래에 보여 준다. 결정일까지 남은 날(D-n)을 함께 표시하고, 시험 트랙의 카드 버튼을 누르면 그 카드의 상세 창이 열린다.

| 필드 | 뜻 |
|---|---|
| `period`, `monthly`, `budget` | 기간, 수입 목표, 시험 예산 |
| `hours`, `hoursNote` | 투입 시간과 그 설명 |
| `decisionDate` | 결정일(`YYYY-MM-DD`) |
| `phase1`, `phase2` | 1단계 목표, 2단계로 넘어갈 신호 |
| `tracks` | 시험 트랙 목록. `name`, `cards`(카드 번호), `budget`, `goal` |
| `rules` | 결정 규칙(문장 목록) |

## 아이디어 필드

| 필드 | 뜻 | 값 |
|---|---|---|
| `no` | 카드 번호 | 숫자. 새 아이디어는 마지막 번호 다음부터 |
| `title` | 이름 | 문자열 |
| `icon` | 타일 아이콘 | 이모지 하나. 비우면 이름 첫 글자 |
| `image` | 타일 이미지 | 선택. 이미지 주소를 넣으면 아이콘 대신 표시 |
| `category` | 분류 | `asset` 자산 투자, `unmanned` 무인·임대, `commerce` 커머스, `content` 디지털 콘텐츠, `service` 대행·서비스, `mine` 내 아이디어 |
| `status` | 상태 | `candidate` 후보, `reviewing` 검토 중, `testing` 시험 중, `active` 진행 중, `hold` 보류 |
| `draft` | 초안 여부 | `true`면 카드에 '초안' 표시. 직접 검토를 마치면 `false` |
| `summary` | 한 줄 설명 | 문자열 |
| `scores` | 평가(1~5) | 부담: `capital` 초기 자본, `time` 투입 시간, `upkeep` 유지 노력, `risk` 리스크(적을수록 가벼움) / 기대: `fit` 역량 적합, `income` 수익 규모, `lasting` 지속성(한 번 만든 것이 계속 돈이 되는 정도)(많을수록 좋음) |
| `next` | 다음 행동 | 문자열 |
| `note` | 고민 메모 | 문자열. 상세 창에 표시 |
| `links` | 연결 | 선택. `[{"no": 18, "why": "이유"}]`. 한 쌍은 한쪽 카드에만 적으면 되고, 화면에서는 방향 없는 선 하나로 합친다 |
| `source` | 출처 | 선택 |
| `created` | 카드 만든 날 | `YYYY-MM-DD`. 이날부터 7일 동안 카드·관계도에 NEW 표시가 붙는다. 페이지에서 새로 추가하면 자동으로 오늘 날짜가 들어간다 |
| `updated` | 카드 수정일 | `YYYY-MM-DD` |

카드를 고치면 파일 맨 위의 `updated`도 같은 날짜로 바꾼다. 화면의 '마지막 수정'이 이 값을 쓴다.

## 로컬에서 보기

`ideas.json`을 `fetch`로 읽기 때문에 `index.html`을 더블클릭해 열면 목록이 뜨지 않는다. 이 폴더에서 정적 서버를 띄운 뒤 http://127.0.0.1:8341 로 접속한다.

```bash
python -m http.server 8341 --bind 127.0.0.1
```

## 반영 시간

`main` 브랜치에 푸시하면 GitHub Pages가 1~2분 안에 다시 배포한다. 화면은 `ideas.json`을 매번 새로 확인하므로 새로고침만 하면 된다.
