저장 설정

GitHub에 바로 저장

토큰을 연결하면 저장할 때마다 저장소의 ideas.json이 바로 고쳐집니다. 다른 기기와 공개 페이지에도 반영되며, 공개 페이지는 1~2분 뒤에 바뀝니다. 토큰은 이 브라우저에만 보관됩니다.

토큰 만드는 법
  1. Fine-grained token 만들기 화면을 엽니다.
  2. Repository access에서 Only select repositories를 고르고 future-income만 선택합니다.
  3. Permissions의 Repository permissions에서 Contents를 Read and write로 바꿉니다.
  4. 만료 기간을 정해 생성한 뒤, 토큰을 위 칸에 붙여 넣고 연결을 누릅니다.

이 저장소 하나의 파일만 고칠 수 있는 토큰이라 다른 저장소에는 영향이 없습니다. 공용 PC에서는 연결하지 마세요.
